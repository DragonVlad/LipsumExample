# LipsumExample

**[Посмотреть живой сайт (Github Pages)](https://dragonvlad.github.io/LipsumExample/)**

Практический проект по верстке корпоративного сайта на основе графического макета. Главная цель - отработка навыков точного позиционирования элементов и построения гибких сеток. 

## 🛠 Технологии и инструменты
* **HTML5** - семантическая разметка (`<nav>`, `section`, `address`)
* **CSS3** - построение сеток, импорт стилей, кастомные шрифты
* **Flexbox** - позиционирование блоков контента, списков и интерактивных элементов
* **SVG-графика** - использование векторных иконок
* **Github Pages** - автоматический деплой и хостинг проекта

## 📐 Реализованный функционал
* Полноценная семантическая структура документа.
* Построение многоколоночных сеток (блоки новостей, контактов, карточки товаров).
* Реализация аккуратных декоративных элементов (пунктирные и сплошные разделители).
* Стилизация интерактивных элементов (эффекты `:hover` для ссылок, сброс дефолтных стилей кнопок).
* Оформление блока контактов с выравниванием иконок и текста по горизонтали.

---
* Проект выполнен в рамках демонстрации навыков структурированной верстки сайтов по макетам.*
