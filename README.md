# LipsumExample

Этот проект содержит пример **HTML и CSS** верстки. Проект не является функциональным приложением, а служит для демонстрации навыков верстки сайта по макету. В качестве контента используется стандартный текст **"Lorem Ipsum"**. В нем применяются методология БЭМ, SVG-графика, CSS-импорт, позиционирование элементов, Flexbox, работа с курсором мыши, изменение заднего фона элементов, работа с псевдо-классами и шрифтами.
